## New

- Torrents use every connection: each one joins the swarm as a peer of its own and they split the pieces
- Each connection can have a PIA region of its own, so each tunnel gets its own exit IP; Spread automatically gives each tunnel the nearest free region
- Each tunnel keeps a colour of its own, picked from its tile
- A PIA region picker grouped by country, with latency and which tunnel uses each region
- Hide a connection so it is never used; Unhide brings it back
- Peers per torrent, per connection, in Torrents settings
- Torrent Details shows peers, swarm, ratio and the share of data each connection's peers wasted
- Download as folder asks where to extract; a split archive asks once

## Improved

- Torrent file picker: an icon for each file's kind, folders dimmed, a folder's total size
- A torrent shows progress squares in each connection's colour, as an HTTP download does
- A torrent's ratio, size and time left count only the files you chose
- A torrent's time left no longer jumps after a restart while its data is checked
- Torrents under VPN only find peers right after the engine starts
- Two connections' PIA tunnels no longer take one server from each other
- The background tint is a slider
- A speed never wraps between its number and unit
- A connection that another program reroutes (often a VPN app's split tunnel) says so
- engine.log and Copy diagnostics leave out your own data, so a log can be sent in

## Fixed

- The engine could crash while a torrent used several connections, or when a tunnel restarted
- The torrent file picker showed "[object HTMLLabelElement]" for files at the torrent's root
- A folder deleted during extraction failed the download instead of pausing it
- A torrent's tracker or web seed could point at this PC or the local network
