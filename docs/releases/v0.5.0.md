### Download as folder

- A `.zip` can now be downloaded straight into a folder: each file in it is extracted and checked as soon as its part of the archive has arrived, and that part of the download is freed. You end up with the folder, never the `.zip`. A 100 GB ZIP that extracts to 140 GB needs about 140 GB of free space instead of 240 GB.
- Switch it on with the box when adding a `.zip` link, in a download's Details, or for every new ZIP in the settings (off by default). Switched on by hand, it asks where to extract while the download already runs.
- The archive's list of files is fetched first, then connections are sent to the front of the next file not yet downloaded, so files complete, and are freed, sooner.
- Files over 1 GB are extracted as their bytes arrive and freed behind the decompressor, so one huge file inside the ZIP doesn't need its whole size twice.
- Handles ZIPs compressed with Stored, Deflate, Deflate64 (as Windows Explorer writes large files) and Zstandard, including ZIP64. Encrypted or split archives, other methods, or a server that doesn't allow split downloads: the file is downloaded as a normal `.zip`, with the reason in Details. A Zstandard archive that needs more than 256 MiB of memory to decode stops with a message saying so.
- Every file is checked against the archive's CRC. One that comes out wrong is downloaded again; twice wrong pauses the download and names the file. A checksum you entered turns the mode off, since there's no whole archive to check.
- The folder it extracts into can be changed while it runs: a rename on the same drive, a copy to another drive (only the bytes still held), refused with a message if a file in it is open. Details warns first if a move would download something again.
- **Change…** lists your recent extraction folders and the Save folder, so the toolbar popup stays open; **Other folder…** opens Windows' folder picker, in front of Firefox.
- After a crash or a pause, finished files are left alone, and a file that was half-extracted starts over.

### Download list

- Cards show what matters at a glance: progress, speed and time left, the connections in use ("via Ethernet 4× · Wi-Fi 2×"), and one pause/resume button. Show in folder, Copy link and Remove are in a ⋯ menu.
- A connection only gets its own row on the card when it has a problem (server busy, failed, waiting). All of them are in Details.
- Errors and pause reasons show in red where the progress line was.
- Problems and downloads waiting for you come first, then running, seeding, queued and paused ones. Finished downloads shrink to one line under a **Clear finished** link; click a name to open it again.
- Details is grouped into Connections, Folder, File and Checks. The landing page and checksums show as values with an **Edit** button. Long links stay on one line.
- A seeding torrent shows its upload speed and ratio against your seed ratio target.
- The header shows the total speed and **+ Add**; Pause all and Resume all appear when two or more downloads can use them.
