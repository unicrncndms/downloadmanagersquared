### VPN port forwarding for imported tunnels

- An imported WireGuard `.conf` whose VPN server answers NAT-PMP (Proton VPN on P2P servers) gets a forwarded port for torrents by itself, renewed while the tunnel is up. Built from Proton's published guide, not yet tested against Proton's servers.
- For a fixed port set in your provider's panel (AirVPN), type it into the new **Port** box next to the imported tunnel. It stays with that tunnel when you import the config again and goes when you remove the tunnel.
- NAT-PMP requests only go to private gateway addresses, never to a public DNS server named in the config.
- A `.conf` without an IPv4 DNS server is refused with a message saying it needs one, instead of a tunnel that resolves nothing.
- A `.conf` tunnel whose server stops answering says its config may have expired (Proton's configs expire or are revoked on logout).
- [docs/vpn-providers.md](https://github.com/unicrncndms/downloadmanagersquared/blob/v0.4.0/docs/vpn-providers.md) explains what a `.conf` needs and which providers offer one.

### Tray and Downloads window

- A left click on the tray icon opens the Downloads window; a right click shows the menu.
- The tray menu is dark in Windows' dark mode and lists only the interfaces carrying a download, with Pause all and Resume all.
- The Downloads window's two pages share one header with the engine status and tabs between downloads and settings.

### Downloads and privacy

- Files served from Google Cloud Storage are checked against the MD5 the server sends, when you haven't pasted a checksum.
- Download cookies saved by an older version are encrypted at the first start, and download files set aside as unreadable keep no cookie values.

### Under the hood

- Tunnels were rebuilt as one module with a PIA and an imported-config provider. A forwarded port can no longer outlive its tunnel.
- A forwarded port typed in with an earlier build moves from the settings to its tunnel at the first start.
- New tests check that each interface really sends from its own address. CI runs staticcheck, and Dependabot proposes updates monthly.
