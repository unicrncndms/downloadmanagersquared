### A new mark

- DMS² has a new mark: two chevrons in two connections' colours on a navy tile. The tray, the exe, setup, the extension and the page headers all use it.

### FTP, FTPS and SFTP

- **FTP and FTPS:** paste an `ftp://` or `ftps://` link, or click one on a page. It downloads over every connection, anonymously unless the link has a login. The password is kept encrypted and never shown. `ftp://` is unencrypted; `ftps://` is encrypted.
- **SFTP:** paste an `sftp://user@host/path` link, with a password in it or a key file under Options. Each connection opens its own SSH session and reads its part.
- The first time an SFTP server is met you are asked to trust its key fingerprint, before any login is sent. A changed key fails the link with a warning and is never accepted by itself.
- SFTP logins and trusted servers are listed in **Settings → SFTP logins**, and each can be removed there.
- A server that allows only one login at a time costs a connection, not the link.

### Queue window

- **Settings → Queue runs only between** sets, per weekday, the hours the queue runs. Outside them nothing new starts, running downloads pause and seeding torrents stop; they resume when the window begins. A download you start yourself still runs. No day set: no limit.

### Other new things

- **Add link from clipboard** in the tray menu adds the links on the clipboard (http, https, ftp, ftps, sftp, magnet). It skips links already in the list and names the file.
- The Downloads window opens where you left it.
- A welcome page leads to the engine's download when the extension runs without it.
- Sizes and speeds use base 1000 everywhere: the pages, the tray and the balloons. 1 MB is 1,000,000 bytes.
- Partly written squares in the list show in the colour of the connection writing them, so a square with bytes on disk never goes blank, and a square being written shows its real written share.

### Fixes

- Removing a download while the list is drawn no longer crashes the engine, and a removed download stays gone.
- A download in **Needs you** shows its "!" again instead of an empty tile.
- Slow lines are no longer counted as stalled.
- A checksum changed while a download is being verified is checked.
- A split archive's parts hold still while one moves, leave no `.part` files and back off after a failed step. A finished download's speed counts only the time it was active.
- One balloon per group instead of one per part.
- A torrent's port is the live one after you change it.
- The elevated copy of the engine is held unchanged while it runs, closed windows release WebView2, uninstalling restores the registrations when you decline the administrator prompt, and the tray tooltip never cuts an emoji in half.
- Torrent files are kept inside the save folder.
- When the VPN's adapter list fails, the VPN check runs again instead of stopping.

### Security

- An imported WireGuard `.conf` (it holds a private key) is kept encrypted with Windows; configs saved readable by an older version are encrypted at the next start.
- The engine refuses oversized requests with a reply, and the extension can no longer make it quit.
- DMS² tells you when the extension's version and the engine's may not work together.
