## New

- Folder rules: send a file type (.iso) or a site to a folder of its own
- "Always take over downloads from" list for sites, next to the never list
- When the file already exists: keep both, replace, skip, or ask
- Adding a link already in the list asks first: Add anyway, Open it or Cancel
- Rename a running, paused or queued download from its card
- Copy diagnostics in a download's Details, for bug reports
- Each connection shows what it usually manages ("usually 8.4 MB/s")
- A slow download says why: the server sends no faster, limits requests, or one connection is slow
- Connections says when Windows may drop Wi-Fi next to a cable or a tethered phone, and offers Keep all connected

## Improved

- Cards say what went wrong in plain words instead of an error code
- A full or missing drive pauses instead of failing; a deleted .part starts over
- A failed extraction no longer looks like a failed download
- The VPN dropping under VPN only is said once in a tray balloon, and again when it is back
- Switching a download to VPN only stops its plain requests at once
- A link whose every connection fails says Retrying and why, not "Checking the link…"
- The connection strip says "server busy" only when a server pushed back
- Pages open where you left them: Settings at its section, the list at its scroll
- Tray speeds and times read the same as in the pages
- A numbered copy of a .tar.xz stays "linux (1).tar.xz"

## Fixed

- A torrent with ":" in its name wrote into a hidden stream instead of its file
- Torrent files with ? or * in their names, or very long names, failed to open
- Two long torrent file names that differ only at the end became one file
- A web page could hand DMS² a magnet or FTP link without a click
- Show in folder on a file deleted outside DMS² opened the Desktop
- A folder dialog left open over a minute said "engine did not answer"
- A second copy of a file briefly joined a split-archive group with the first
- The duplicate question said "This link" before the file had a name
- The activity log said "Paused: Paused:"
- Every PIA app connect left one more connection in the settings

## Known limitations

- The extension can reach you from its store before the engine is published; until then the popup says "A newer engine is on its way" and everything keeps working
