downloadmanagersquared (DMS²): downloads over all your connections at once.

1. Run dms-engine.exe from this folder (SmartScreen: "More info", then "Run anyway").
2. Choose where to install (Program Files by default; Windows then asks for administrator rights)
   and the shortcuts you want. It starts in the tray and offers the Firefox extension: click OK.
3. LibreWolf, Waterfox or Floorp: open the link it shows in that browser instead.
4. Download a file of 100 MB or more in Firefox: DMS² takes it over.

More, including how to uninstall: https://github.com/unicrncndms/downloadmanagersquared#readme
