Welcome to DMS²

DMS² downloads large files over all your network connections at once. This page opens once, after install.

First, the engine

DMS² is two parts: this extension and a small Windows app, the engine. The engine does the downloading, because an extension can't use several network connections at once. Without it this extension does nothing.

  1. (a zip from GitHub)
  2. Open the zip and run dms-engine.exe. Windows SmartScreen warns because the program isn't code-signed: choose More info, then Run anyway.
  3. Follow its setup. This page notices when the engine connects.

Connected, you're set

The engine is running. Check your connections, or use the DMS² button on the toolbar.

What DMS² takes over

Download as usual. Large files (100 MB or more by default), magnet links, .torrent and Metalink (.meta4) files go to DMS² by themselves. For any other link, use Download with DMS² on its menu.

Containers

Firefox will ask you to enable containers. DMS² uses one container per connection, so a site that gives each IP its own link opens through the connection it is meant for.

Private windows

Running DMS² in private windows is optional. Allow it in Firefox's extension settings if you want downloads started in a private window taken over too. A login from a private window is never copied to DMS²'s pages, so it stays in that window.

Your downloads and settings

  • The DMS² button on the toolbar lists your downloads. The engine runs in the tray; its icon there opens the Downloads window.
  • Connections & settings is the gear in the header of that list.
  • A second connection (another network, a phone, a VPN) is what adds speed. Check your connections.
